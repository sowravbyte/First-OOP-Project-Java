# 🌡️ Java Temperature Converter

> **My first OOP-based project using Java** 🚀

A simple and user-friendly **Temperature Converter** built with Java.
This project was created as part of my journey to learn **Java, Object-Oriented Programming (OOP), methods, loops, switch statements, and input validation**.

---

## ✨ Features

* 🌡️ Celsius → Fahrenheit
* 🌡️ Fahrenheit → Celsius
* 🌡️ Celsius → Kelvin
* 🌡️ Kelvin → Celsius
* 🌡️ Fahrenheit → Kelvin
* 🌡️ Kelvin → Fahrenheit

## 📐 Conversion Formulas

### Celsius → Fahrenheit

```text
°F = (°C × 9/5) + 32
```

### Fahrenheit → Celsius

```text
°C = (°F − 32) × 5/9
```

### Celsius → Kelvin

```text
K = °C + 273.15
```

### Kelvin → Celsius

```text
°C = K − 273.15
```

### Fahrenheit → Kelvin

```text
K = (°F − 32) / 1.8 + 273.15
```

### Kelvin → Fahrenheit

```text
°F = 1.8 × (K − 273.15) + 32
```
